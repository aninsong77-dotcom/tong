# 통 · 설문부터 통계 해석까지

통계 용어를 몰라도 질문에 답하며 사다리를 내려가 내 연구에 맞는 통계 기법을 고르고, 그 변인으로 설문을 만들고, 응답을 모아 계산하고, AI와 함께 결과를 해석하는 대학원생용 도구입니다.

**바로 쓰기: https://aninsong77-dotcom.github.io/tong/**

- 통계 기법 고르기(연구모형 카드와 빈칸으로 가설 만들기, 그 모형으로 할 수 있는 분석 목록, 또는 질문으로), 설문 만들기(척도 원본 PDF·사진에서 자동), 표본 수 계산(G*Power와 같은 공식, 매개는 모의실험), 모델 검토·모의 실행·가설 확정(확정 뒤 분석은 확증/탐색적 표시), 구글 폼 스크립트, 응답 취합·정리(중복·이상치·결측), 표본 확인(표 1)·측정 점검(신뢰도·탐색적 요인분석·확인적 요인분석 — 브라우저 속 R의 lavaan, 응답 자료는 밖으로 나가지 않음)·사전 분석(정규성·표 2 상관·VIF), 예비조사/본조사 구분, 통계 계산(반복측정·혼합설계·맥니마·코크란 Q 포함)과 가설 판정, R·SPSS 대조(SPSS 명령문 내려받기), 결과 해석(내가 먼저 읽고 AI가 논문투로 풀어 쓰기)·허점 점검
- 클리닝(주의 확인 문항, 불성실 응답 세 기준, 연구 대상 조건, 값 정리, 직접 빼기)과 [가설 전부 계산하기], 논문용 결과 그래프(PNG 컬러·흑백)
- 설치 없이 브라우저에서 동작합니다. 응답 원자료는 브라우저 밖으로 나가지 않습니다.
- PC 연구 폴더(크롬·엣지)를 연결하면 작업이 폴더에 저장되고, 같은 폴더에서 Claude Code로 해석·R 분석·허점 점검을 맡길 수 있습니다.
- 사용법은 사이트의 [사용 설명]에 있습니다.
- 계산 검증: `tests/`의 테스트로 R과 비교합니다(분석 23가지의 효과 78개, t검정·회귀·요인분석·베이즈 인자, 확인적 요인분석은 브라우저 속 lavaan과 진짜 R lavaan 대조). 동의·중복 판정, 계산이 안 되는 자료, 기법 고르기, 가설 읽기 같은 경계 상황도 확인합니다. 커밋할 때마다 GitHub Actions가 자동으로 돌립니다. 결과마다 [R 코드 보기]로 그 결과를 만든 기본 R 코드를 볼 수 있습니다.
- 다른 AI나 사람에게 계산 코드를 보여 주려면: [`review/tong_calc_core.js`](review/tong_calc_core.js) (계산 부분만 모은 파일, 안내는 [`review/README.md`](review/README.md))

갈림길 규칙은 아직 교재 자료 없이 통계 지식으로 만든 것이라 모두 [AI 지식] 꼬리표가 붙어 있습니다. 결과는 지도교수와 함께 확인하세요.
